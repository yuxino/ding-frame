# ADR 0001：采用临时处理链路，不建立永久视频库

## 状态

已接受。

## 背景

Koma 的目标是分析短视频，而不是管理视频资产。视频只在分析和回看期间临时保存，不作为长期视频库使用。

## 决策

服务端使用操作系统临时目录承接上传或 URL 下载；抽帧和文本结果仅存在于进程内存与任务临时目录。中间音频在分析后立即删除，视频、结果与抽帧在短 TTL 后整体删除。ASR 将临时 MP3 切片直接发送给模型，不建立额外的永久对象存储。

## 取舍

- 优点：数据生命周期清晰、早期不需要数据库、部署简单。
- 代价：服务重启后任务消失；多实例部署无法共享任务和结果；结果过期后不可恢复。
- 如果后续需要并发和历史记录，应引入 Redis、队列和明确的持久化方案。
